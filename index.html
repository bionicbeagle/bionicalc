BioniCalc

a reactive calculator

Type a calculation with your keyboard or the pad, then press ⏎ for a new line. Starting a line with an operator continues from the result above.

Tap any result to use it as a live value in the line you're editing, and tap any number to retype it — everything that depends on it updates instantly.

Hover a line to label it ("subtotal", "VAT") — labels show up wherever the result is referenced. Undo any change with ⌘Z / Ctrl+Z.

Drag the ⠿ handle (or press ⌥↑ / ⌥↓) to reorder lines — references stay live wherever their lines sit.

Add a unit after a value — type it, or use the unit row on the pad (… shows all of them): 12cm + 30mm = 15 cm, 100km / 2h = 50 km/h. A unit after a reference converts it.

The tabs above the keypad are projects; the tabs up here are sheets within the current project (drawers, carcase, …) — every sheet is its own page with its own undo. Tap the active tab to rename it.

Keep master parameters on one sheet and label them — they appear in the summary under the project tabs (and behind the ref key), ready to insert as live values anywhere in the project.
